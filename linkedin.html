I founded Tribunus in October 2024 in San Francisco to build the local-first stack for AI inference — the open-source layer that lets engineers run large language models on their own hardware, with explicit authority, compile-time guarantees, and a replayable record instead of opaque logs. The product I am shipping in 2026 is Tessera Studio — a desktop app for running LLMs locally with calibrated, audited per-tensor quantization. It is built on Tessera, my C++ fork of llama.cpp that takes calibration seriously. macOS today, Linux in progress. Before Tribunus I worked as a software engineer in the San Francisco Bay Area, and as a freelance photographer and designer. Tribunus is an independent, founder-led software company. We build the open-source stack for running AI inference and agents on your own hardware. Founded in October 2024 by Julian Torres in San Francisco, California. The product we ship in 2026 is Tessera Studio — a desktop app for running large language models locally with calibrated, audited per-tensor quantization. macOS today, Linux in progress. The C++ side (Tessera) is a fork of llama.cpp that takes calibration seriously: per-tensor policy evolved by a small genetic algorithm, schema-versioned policies, runtime agreement with the offline reference down to F16. Native speculative decoding (DFlash / DSpark). Apple Neural Engine prefill on M-series Macs. Four rules, all the time: 1. Compile-time, not runtime — decisions are frozen before execution. 2. Local-first, federated when needed — your hardware, your data, your model. 3. Authority, not ambient access — every plugin and tool gets explicit capability grants. 4. Verifiable by construction — every run keeps a replayable record. Tribunus is open source. The site code is AGPL-3.0; the Tessera fork ships under LICENSE-TESSERA (PolyForm Noncommercial) with commercial licenses available. Founded by Julian Torres. Sole maintainer. Self-funded. Raising a pre-seed.
