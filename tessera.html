What it is

Runs large models on your own computer.

Tessera Studio is a Swift desktop app for running large language models on your own machine. It's built on Tessera — a fork of llama.cpp with per-tensor calibration: each tensor gets quantization settings tuned to keep output accurate while using less memory.

The app handles the workflow: an agent loop, manifest-based skills, and files that stay on your computer. The C++ side handles the inference. Both sides keep a log you can open and check.

What ships

The four capabilities in flight.

Each is implemented, not promised. Where a capability is partial, the product page says so.

Per-tensor calibration T640

Each tensor gets its own quantization settings, tuned to keep output close to the original model while using less memory.

Speculative decoding DFlash / DSpark

Native speculative decoding on Apple Silicon. The verifier and drafter share a tokenizer, with per-step telemetry for training.

ANE prefill Apple Silicon

Verifier prefill runs on the Apple Neural Engine through a Core ML package, with IOSurface async hand-off into the GPU. M-series only, opt-in via the auto-trigger.

Skills system Swift

Manifest-based skills (SKILL.md). Skills load into the agent's prompt on demand, with native macOS integration — Reminders, Calendar, and more.

Stack Swift SwiftUI C++ (Tessera fork) Core ML ANE CMake Xcode Linux · planned
