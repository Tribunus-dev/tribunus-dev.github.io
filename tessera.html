// what it is

Calibrated quantization. Local inference. Real receipts.

Tessera Studio is a Swift desktop app for running large language models on your own machine. It is built on Tessera — a fork of llama.cpp that takes calibration seriously. Per-tensor quantization policies are evolved by a small genetic algorithm; the receipts are schema-versioned; the runtime agrees with the offline reference down to F16.

The app gives that stack a real surface: a Swift app core, a manifest-based skills system, an agent loop that survives a restart, and a real local-first file system. The C++ side handles the inference; the Swift side handles the workflow. Both sides ship with receipts.

// what ships

The four capabilities in flight.

Each is implemented, not promised. Where a capability is partial, the live site says so.

Per-tensor calibration T640

Small GA per tensor over (threshold, outlier fraction, AWQ alpha, AWQ clip). Fitness is round-trip error against the BF16 source, with held-out rows. Schema-versioned receipts.

Spec decoding DFlash / DSpark

First-class drafters on Apple Silicon. Verifier and drafter share a tokenizer. Per-step telemetry (llama.tessera.spec.v1) for distillation or rejection sampling.

ANE prefill Apple Silicon

Verifier prefill runs on the Apple Neural Engine through a Core ML package, with IOSurface async hand-off into the GPU. M-series only, opt-in via the auto-trigger.

Skills system Swift

Manifest-based skill loading (SKILL.md YAML). Skills are scanned, parsed, and injected into the agent's prompt on demand. First-class macOS integration: Reminders, Calendar, etc.
