Tessera Studio

developer preview · macOS

A Swift desktop app for running LLMs locally. Calibrated per-tensor quantization, native speculative decoding, and Apple Neural Engine prefill on M-series Macs.

  • Built on Tessera — our C++ fork of llama.cpp with evolutionary per-tensor calibration (T640) and DFlash / DSpark drafters
  • Swift app core with a real agent loop, manifest-based skills (SKILL.md), and a local-first file system
  • Every run keeps a log you can check — what loaded, what ran, what happened
