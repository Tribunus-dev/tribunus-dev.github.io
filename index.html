Tessera Studio

developer preview · macOS

A Swift desktop app for running LLMs locally. Calibrated per-tensor quantization, native speculative decoding, Apple Neural Engine prefill on M-series Macs, first-class skills system.

  • Built on Tessera — a fork of llama.cpp with per-tensor evolutionary calibration (T640), DFlash/DSpark drafters, and ANE prefill via Core ML
  • Swift app core with a real agent loop, manifest-based skills (SKILL.md), and a local-first file system
  • Designed for the engineering workflow — quantized models, receipts, and audit trails you can replay

The accelerator application process taught me to name the asks. These are the five concrete things I am looking for in 2026. If one of these is you, the contact is at the bottom of the page.

Beta users on Mac & Linux

Run Tessera Studio on a real model, on a real machine, with a real workload. File honest issues. I ship to early users first, not to marketing.

→ install · real model · honest issues
02

Co-engineers

Swift / SwiftUI on the app side. C++ / quantization on the inference side. UX / macOS HIG where it matters. Small, focused PRs. I review personally.

→ open PR · small · focused
03

Quantization researchers

People who have read the T640 / DFlash / DSpark papers and want to push them. Tessera is a fork of llama.cpp that takes calibration seriously. The receipt trail is the contribution surface.

→ per-tensor policy · receipts
04

Advisors

People who have shipped a Mac desktop product or a fork of llama.cpp and are willing to spend an hour a week. I pay in equity, attention, and prompt replies.

→ shipped before · 1 hr/week
